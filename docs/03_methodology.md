## Anwendung von IPERKA

This project follows the Swiss project management method IPERKA. This method consists of sic consecutive phases that build on one another.

| Phase | Anwendung im Projekt | Dokumentation |
|---|---|---|
| Informieren | Problem, Zielgruppen und Anforderungen analysieren | [Projektübersicht](01-project-overview.md) und [Anforderungen](02-requirements.md) |
| Planen | Systemstruktur, Prioritäten und Vorgehen festlegen | [Systemdesign](04-system-design.md) und [Roadmap](08-roadmap.md) |
| Entscheiden | Lösungsvarianten vergleichen und Auswahl begründen | [Entscheidungsprotokolle](../decisions/README.md) |
| Realisieren | Geplante Funktionen im Notion-System umsetzen | [Umsetzung](05-implementation.md) |
| Kontrollieren | Anforderungen anhand definierter Testfälle prüfen | [Testing](06-testing.md) |
| Auswerten | Zielerreichung beurteilen und Erkenntnisse festhalten | [Einschränkungen und Learnings](07-limitations-and-learnings.md) |
