# Archive: Notion concept

This folder contains the original concept from September 2026, when the first prototype was planned as a Notion template ([ADR-001](../../decisions/ADR-001-notion-as-first-prototype.md)).

The project has since switched to a dedicated web app ([ADR-002](../../decisions/ADR-002-switch-to-aspnet-core-blazor.md)). These documents are kept **unchanged and in their original language (German)** to show how the project evolved. They are no longer maintained.

| File | Content |
|---|---|
| [notion_system_concept.md](notion_system_concept.md) | Original system concept: central databases, page structure, dashboard, formulas |
| [notion_free_plan_limitations.md](notion_free_plan_limitations.md) | Analysis of Notion's free-plan limits (as of 26 September 2026) |

Several ideas carry over to the web app: the IPERKA structure, the separation of central data and filtered views, progress calculations and the project closure with learnings.
